# Atlas → premium CAFM: opportunity analysis

**Research date: 2026-10-17. These are candidate upgrades, not verified deficiencies in your Atlas fork.** Atlas already publicly advertises work orders, asset hierarchies, preventive maintenance, inventory, mobile use and dashboards; its public README also describes automation, purchasing approvals, roles and service-provider assignments. See [ATLAS_BASELINE.md](ATLAS_BASELINE.md) for primary sources. Audit your exact version before building replacements.

Evidence labels: **D** = public help/developer documentation; **M** = product claim/UI illustration; **R** = dated release note; **I** = independent Atlas design inference. None means hands-on validation.

## Recommended sequence

1. **Make the existing engine feel coherent:** design system, navigation, portfolio context, record shell, action hierarchy and technician execution. Reuse working Atlas capabilities.
2. **Connect enterprise operations:** richer location model, SLA/calendar semantics, vendor access, contract links, inspection evidence and purchasing handoffs.
3. **Generalize only proven repetition:** fields/forms, layouts, workflows, integrations and reporting. Add narrowly scoped AI assistance after the action/permission model is trustworthy.

For each candidate, compare a real task in your Atlas version against the linked Facilio documentation. Record current steps, missing context, permission boundaries and an acceptance journey. Screenshots establish layout patterns; they do not establish implementation quality, response time or backend architecture.
