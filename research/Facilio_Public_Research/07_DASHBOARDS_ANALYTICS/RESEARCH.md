# Dashboards, reporting and portfolio command centers

Research date: **2026-10-17**. These observations summarize public Facilio documentation and product imagery. They do not verify a live tenant. Atlas was not inspected; suggested upgrade areas are hypothetical.

## Three complementary interaction layers

[Views and Dashboards](https://facilio.com/help/docs/user-guide/getting-started/views-and-dashboards/) distinguishes reusable record views from composed dashboards. Views preserve filtering, sorting and columns and can be organized in folders; scheduling delivers selected results by email. Dashboard construction combines text, images, components and cards. Cards can aggregate readings, compare periods and apply conditional presentation. This is useful evidence for giving different roles a stable workspace while preserving a common underlying data model. Analyze the configuration dialogs and view/folder navigation separately from the final dashboard appearance.

[Working with Analytics](https://facilio.com/help/docs/analytics-dashboards/data-analytics/working-with-analytics/) documents choosing building data points, adding other readings such as weather, applying filters and customizing representation. Reports support dimensions, baselines and time aggregation, with chart-specific presentation controls. Saved reports belong to folders and can be published into dashboards. Export and scheduled delivery exist, with some actions restricted by the chosen report/data types. Access restrictions are configurable. This provides a stronger workflow reference than a marketing image of a finished executive screen.

[Working with KPIs](https://facilio.com/help/docs/analytics-dashboards/data-analytics/working-with-kpis/) describes two metric paths. Module KPIs select a module, site, criteria, measurement and time basis. Reading KPIs calculate expressions over asset/space readings, using a virtual element for the result. The formula builder offers visual expression configuration and alternate expression/code views. KPI details expose current values, limits, trends and calculation logs. This is relevant when distinguishing operational counters from calculated engineering metrics; they need different definitions and review affordances.

The [Pivot documentation hub](https://facilio.com/help/docs/analytics-dashboards/data-analytics/working-with-pivot/) provides a further route into structured analysis. The [reports and dashboards product page](https://facilio.com/cmms-reports-and-dashboards/) supplies contemporary images of derived metrics, pivot analysis and dashboard assembly. Treat those images and broad claims as product presentation, while using the help guides to support detailed interaction assertions.

## Hypothetical Atlas opportunities

A premium enterprise command center could begin with a few actionable questions: where service is deteriorating, which sites carry overdue work, where asset costs are growing and which vendors need intervention. Assess Atlas's existing reporting before adding a general-purpose builder. A plausible sequence is trusted metric definitions, permission-aware saved views, drill-through to operational records, reusable dashboard composition and finally advanced formulas/pivots. Clear time ranges, units, data freshness and filter scope are likely more valuable than many decorative charts. These are design recommendations, not claims that Facilio publicly proves each specific proposed dashboard.

## Evidence limits and reconstruction questions

Public pages demonstrate substantial configuration depth but leave query limits, refresh latency, row-level export behavior, calculated-metric governance and very large dataset performance unresolved. Confirm whether a chosen screenshot represents telemetry analytics, operational module reporting or an executive composition; combining them prematurely can hide different permission and aggregation rules. A research agent should trace one metric from source record through filters and aggregation to a dashboard card and back to its supporting records. No analytics benchmark or verified Atlas feature comparison was performed.
