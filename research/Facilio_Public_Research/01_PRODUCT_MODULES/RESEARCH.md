# Product model and Atlas upgrade map

Research date: **2026-10-17**. This is a synthesis of public sources. No Facilio tenant or Atlas installation was examined.

Facilio’s public material is most useful as a connected operating model: **where work happens → what equipment serves it → who is responsible → what commitment applies → what evidence proves completion → what it costs**. This is an analyst’s organizing model, not a claim about Facilio’s internal database schema.

| Operational layer | Public reference | Atlas upgrade question |
|---|---|---|
| Portfolio and place | [Portfolio management](https://facilio.com/help/docs/user-guide/facilio-modules/portfolio-management/) | Can a user retain site/building/space context while navigating work, assets and metrics? |
| Asset and infrastructure | [Asset management](https://facilio.com/help/docs/user-guide/facilio-modules/asset-management/) | Does a record show operational health, maintenance, downtime, cost, readings and connected entities together? |
| Request and execution | [Service requests](https://facilio.com/help/docs/service-request-management/introduction/) and [maintenance](https://facilio.com/help/docs/user-guide/facilio-modules/maintenance-management/) | Are customer demand, dispatch, technical work and approval separate but connected? |
| External delivery | [Vendors](https://facilio.com/help/docs/user-guide/facilio-modules/vendor-management/) and [SLA policies](https://facilio.com/help/docs/admin-guide/automation-plus/managing-sla-policies/) | Can providers see only their work and obligations, while managers see compliance and service performance? |
| Commercial flow | [Procurement guide](https://facilio.com/help/docs/procurement-guide/introduction/) | Do requisition, competitive sourcing, order, receipt and financial review preserve their links and history? |
| Assurance | [Inspection](https://facilio.com/help/docs/user-guide/facilio-modules/inspection/) | Can reusable templates collect consistent evidence and create accountable corrective work? |
| Management insight | [Views and dashboards](https://facilio.com/help/docs/user-guide/getting-started/views-and-dashboards/) | Can every important exception lead to a filtered list and a concrete action? |
| Platform configuration | [Modules and fields](https://facilio.com/help/docs/admin-guide/customization/managing-modules/overview/), [stateflows](https://facilio.com/help/docs/admin-guide/process-management/stateflows/overview/) | Which repeated configuration needs deserve shared builders rather than new hardcoded screens? |
| Extensions | [Developer portal](https://facilio.com/developers/) | Are data access, embedded UI, standalone apps and external-system actions clearly separated? |
| Assistance | [AI guides](https://facilio.com/help/docs/ai-guide/technician-co-pilot/) | Can assistance inherit existing context, permissions and reviewable business actions? |

## Additional modules retained in the source catalog

The collected Help navigation and sitemaps also expose tenant and booking management, utilities, diagnostics, visitor/kiosk operations, remote monitoring, field-service operations, inventory/parts, safety/permits, user administration and portals. These widen the enterprise CAFM reference without making all of them immediate implementation priorities.

The [platform overview](https://facilio.com/platform-overview/) presents building-system data, diagnostics, analytics, workflow automation and custom applications as a connected layer. Its statements are product positioning; use the module and developer guides to inspect specific interactions. Building-system “agent” documentation refers to integration software, while newer AI pages use “agent” for an assistant/action system. Preserve that distinction.

## What makes the reference valuable

The strongest premium-product cues are consistent record/detail shells, obvious next actions, relationship-based navigation, configuration that resembles the operational task and persona-specific access. Visual polish should accompany understandable states, trustworthy numbers and clear ownership.

For Atlas, start with one end-to-end scenario: a tenant reports an issue at a space, an operator dispatches a vendor, a technician records evidence, a manager checks SLA/completion, and a commercial record preserves the cost. Map every screen to an existing Atlas capability before extending the data model. This scenario and implementation sequence are proposals, not observed Facilio execution.
