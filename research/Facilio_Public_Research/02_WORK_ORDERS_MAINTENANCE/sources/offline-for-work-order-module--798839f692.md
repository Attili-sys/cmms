## Scope summary

Offline work-order support has a constrained capability set. The guide excludes custom workflows/stateflows, embedded apps, custom buttons and some other actions while disconnected; automation and SLA processing resume online. Treat these restrictions as part of the product behavior, not as incidental implementation detail.
