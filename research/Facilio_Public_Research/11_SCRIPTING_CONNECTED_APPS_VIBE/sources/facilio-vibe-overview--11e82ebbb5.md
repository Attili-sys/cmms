## Scope summary

Vibe hosts standalone custom web apps on managed subdomains. Its frontend SDK handles identity and integration actions, with app-scoped functions, data and agent facilities documented alongside it. Use the current CLI and Connections documentation to understand discovery and deployment contracts.
