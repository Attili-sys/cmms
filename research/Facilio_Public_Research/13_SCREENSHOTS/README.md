# Public UI images

1995 unique image files from 2104 original image URLs. Open [GALLERY.html](GALLERY.html) to browse and filter offline. [IMAGE_MANIFEST.csv](IMAGE_MANIFEST.csv) maps each URL to source pages, hashes and local files; JSON retains full source associations.

Images are original embedded documentation/product assets, not captures from a logged-in tenant. They include UI screenshots, diagrams, animations and marketing illustrations. A representative selection was visually checked; the collection has not been individually classified pixel by pixel. Filenames are content hashes so identical files are stored once. Image URLs with different bytes remain separate even when visually similar.

Public URLs on third-party hosts are retained in source notes when they were not downloaded. Access exclusions and errors appear in the access log. No video binaries are packaged. Images retain their owners’ rights; use as research reference, not as assets to ship in Atlas.

Additional registers: [image dimensions/format checks](IMAGE_DIMENSIONS.json), [source-image warnings](IMAGE_SOURCE_WARNINGS.json), and [representative contact sheet](REPRESENTATIVE_CONTACT_SHEET.jpg). Four source PNGs with invalid ancillary checksums remain URL-only references.
