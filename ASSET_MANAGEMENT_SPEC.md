## 3. Contractual Metric Definitions

| Metric | Contractual Formula |
|---|---|
| **Eligible Exposure Hours** | $\max(0,\ \min(\text{range\_end}, \text{now}) - \max(\text{range\_start}, \text{in\_service\_date or created\_at}))$ |
| **Downtime Hours** | Union of clipped `AssetDowntime` intervals `[starts_on, starts_on + duration]` within the window (open intervals clipped at `min(range_end, now)`), with overlapping intervals merged so downtime is never double-counted. |
| **Uptime Hours** | $\max(0,\ \text{Eligible Exposure Hours} - \text{Downtime Hours})$ |
| **Availability %** | $\frac{\text{Uptime Hours}}{\text{Eligible Exposure Hours}} \times 100$ (or `100.0%` when exposure $> 0$ and downtime $= 0$). |
| **MTBF (Hours)** | $\frac{\text{Uptime Hours}}{\text{Unplanned Downtime Event Count}}$ (when unplanned count $> 0$, else `Uptime Hours`). |
| **MTTR (Hours)** | $\frac{\text{Closed Unplanned Downtime Hours}}{\text{Closed Unplanned Event Count}}$ |
| **Maintenance Spend** | $\sum \text{Labor Cost} + \sum (\text{PartQuantity} \times \text{Part Cost}) + \sum \text{AdditionalCost}(\text{include\_to\_total\_cost}=\text{true})$ across Work Orders linked to the asset in the date window. |
| **RAV (Replacement Asset Value)** | Dedicated `replacement_cost` (falling back to `acquisition_cost` only when explicitly labeled), used as denominator for $\text{Annual Maintenance Cost} \div \text{RAV}$. |
